# Strength Block v5

4-week transmutation block (4s → 3s → 3s heavier → 3RM benchmark). Potentiation singles return on heavy days (Wed squat, Thu bench, Sat deadlift), but benchmark week uses opener-like singles before top triples rather than max-effort singles plus max-effort backoffs. Monday variation becomes pause squat (low bar) for hole strength specificity. Same day structure as accumulation for consistency. Incline DB stays as serious bench exposure. Pull-ups twice weekly.

## Overview

- Weeks: 4
- Days per week: 5
- Total workouts: 20
