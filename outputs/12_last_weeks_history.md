## Format Guide
- Weights are in **kg** (converted from lb in source)
- RPE is Rate of Perceived Exertion (6-10 scale, 10 = max effort)
- Each set shows: `reps × weight_kg @ RPE [target_info]`
- target_pct = percentage of 1RM programmed
- target_rpe = RPE target for the set
- target_reps = programmed number of reps
