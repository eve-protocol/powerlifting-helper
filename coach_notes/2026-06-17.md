## Technical theme to carry forward
- Squat: `knees forward, chest through`.
- Do not let rep 3 of a top triple become the old good-morning pattern just because the RPE number is still inside target.
- Accessories: once a set reaches @8 or higher, the next repeated set should usually drop unless the exercise is intentionally being pushed.

## Next-time guidance
- Heavy low-bar benchmark prep: 165kg x1 is validated as a calibration single when warm-ups are normal, but if it looks like today's slow single or lower back is already sore, do not jump the triple aggressively.
- Low-bar triples: 157.5kg x3 is now validated as a target-effort top triple, but only barely from a technical standpoint. For Week 4, 160kg x3 should require better first/second-rep position than today's 157.5kg; otherwise 157.5kg or 155kg is the cleaner bridge.
- Backoff triples: 152.5kg is a reliable position-protection load after the heavy triple. Use it quickly if lower-back soreness appears or if hips start beating the chest.
- Leg extension: 70kg is a valid first set for 10s, but if it reaches @8, drop to 65kg immediately. If left heel discomfort returns with dorsiflexion, keep foot neutral and reduce or skip.
- Standing T-bar row: use 62.5-65kg depending on lower-back feel. If torso fixation is not strict, choose 62.5kg or switch to a more supported row.
- Leg curl: start 25kg for 12s when the day already included heavy squat/deadlift stress. Use 30kg only as a one-set test and do not repeat it after @8+.
- Heel: tomorrow's morning check matters. If heel/Achilles area is more painful, swollen, tender, or push-off feels altered, treat lower-body loading conservatively and avoid aggressive calf/Achilles stretching.
