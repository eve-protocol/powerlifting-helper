## Week 4 objectives for this block
- Low-bar squat: 157.5-160kg x5 @9-9.5, with less hip-rise / chest-lag than the previous 155kg x5 @9 baseline.
- Sumo deadlift: 177.5kg x5 @9-9.5, with cleaner lockout/top-half position than previous heavy rep work.
- Secondary objective: keep bench progressing without letting pressing/accessory overshoots compromise the lower-body tests.

## Current trajectory
- Overall: successful lower-body block with execution caveats. Squat and deadlift both moved up in load, which was the main goal of the block. Deadlift produced the cleanest benchmark relative to target; squat produced a real PR but overshot RPE and still showed the same technical failure mode under limit fatigue.
- Squat: positive on strength, mixed on position. High bar on Monday was controlled at 130kg x5 @6.5. Low-bar hit 160kg x5 @10, which proves capacity and beats the 157.5kg first-target, but it was not the clean stretch outcome because reps 4-5 became hip/back dominant.
- Deadlift: strongly positive. Paused deadlift on Tuesday reached 165kg x3 @6.5 on the preferred bar, then Saturday regular sumo hit 177.5kg x5 @9.5 with appropriate backoffs. That meets the block goal after Week 3's equipment-contaminated session.
- Bench: still strong, but less controlled. Paused bench Monday was fine, but Thursday's heavy bench missed 122.5kg x5 and logged 122.5kg x4 @10. This looks more like fatigue, pec/shoulder hesitation, and load-selection error than a true strength regression, especially because 120kg x5 x2 @9 was already achieved in Week 3.
- Accessories: still the least disciplined part of the block. Pull-ups, chest fly, curls, leg curl, lateral raises, and Larsen all had examples of RPE drifting above target.

## Main evidence
- High-bar squat: 125kg x5 easy, then 130kg x5 @6.5. Useful developmental work and not fatiguing.
- Paused bench: 105kg x3, then 110kg x3 @6.5 with controlled pauses.
- Paused sumo deadlift: 162.5kg x3 @6.5 and 165kg x3 @6.5. This cleared the Week 3 bar/grip concern and supported the Saturday benchmark attempt.
- Heavy low-bar squat: 160kg x5 @10. This is a 5kg increase over the 155kg x5 @9 baseline, but the RPE and hips-first finish mean it should be counted as a strength win, not a technical model set.
- Heavy bench: 122.5kg x4 @10, then 110kg x5 @7 and @7.5. The top set missed the planned fifth rep, but the block still includes 120kg x5 x2 @9 from Week 3.
- Heavy sumo deadlift: 177.5kg x5 @9.5, then 160kg x5 and 162.5kg x5 @7. Video showed a hard but completed top set and controlled backoffs.
- Light low-bar after deadlift: 140kg x3 @6 and 140kg x3 closer to @5.5. Good enough after the deadlift PR, and appropriately not chased.
- Larsen press: 110kg x4 @6 and @7. First set was perfect; second set slightly overshot.

## Risks to carry into the next block
- Squat strength improved, but the same compensation appears when effort gets high. The next block should not reward more load unless chest and hips stay more synchronized.
- Deadlift is now moving, but the top-half/lockout pattern remains the main technical limiter. The next block should use heavier triples to strengthen that position, not simply test it.
- Bench is not weak, but the pec/shoulder attachment warning and repeated accessory overshoots need respect. Pressing should stay productive without forcing chest fly or secondary pressing when local tissue is irritated.
- Accessory load discipline needs to improve. The pattern is predictable: first set on target, second or third set drifts above target unless the load is reduced earlier.

## Next block implications
- Strength block low-bar 3RM: 162.5kg x3 is a reasonable first benchmark target if warm-ups show better chest/hip timing. 165kg x3 should require cleaner execution than the final reps of 160kg x5.
- Strength block sumo 3RM: 185kg x3 is realistic if warm-ups preserve lat/back/hip position through lockout. 187.5kg x3 is a stretch only if the top half looks cleaner than the 177.5kg x5 finish.
- Bench: 122.5kg x5 remains plausible when warm-ups are normal and the pec/shoulder area is quiet. Do not plan 125kg x5 until 122.5kg x5 is completed or clearly available.
- Accessories: start from the known controlled loads and reduce earlier after an on-target first set. Benchmark blocks are not won through extra @9 isolation work.

## Block verdict
Volume Block v6 did what it was supposed to do: lower-body estimated strength moved up again. Squat reached 160kg x5 and deadlift reached 177.5kg x5, both meaningful improvements from the baselines. The block did not fully solve the technical tendencies, but it exposed them under heavier load while still producing progress. The next block should convert this into heavier triples with stricter position standards.
