- Low-bar squat: 130kg x6, 130kg x6 @6.

## Coaching assessment
- Deadlift was the main success of the day. 160kg for all 3x6 landed exactly in the target RPE range and held together across sets. Video showed no grind and clean lockouts.
- Main deadlift technical pattern: hips still rise slightly before the bar breaks, making the start a bit more back/hinge-dominant than ideal sumo. This did not become a major breakdown today, but it remains the main thing to clean up.
- Best deadlift cue from today: `pull slack, squeeze lats, push the floor apart`. The intent should be wedge first, then drive — not yank and find tension after the bar moves.
- Squat was appropriate light work after deadlifts. 130kg x6 stayed around the intended light range, though set 2 logged @6 and therefore slightly exceeded the 5-5.5 target.
- Important equipment note: set 1 used squat shoes and felt easier; set 2 used flat slippers and felt harder. Side-by-side video confirmed the squat shoes produced slightly more forward knee travel, a more upright torso, and less hips-leading/forward pitch. Flats made the rep look more hip-dominant, though set order/fatigue is a confounder.
- Squat technical pattern remained the same as earlier in the week: slight hips-leading / chest-lag out of the hole. Not severe, but still the limiting pattern to watch as load rises.
- Larsen press load selection overshot on set 2. 100kg x8 was clearly under target, but 105kg x8 landed @7.5 against a 6-6.5 target. The better next-time jump from an easy 100kg first set is probably 102.5kg unless the first set is truly very fast and fresh.
- Chest fly: 85kg x12 was the right target load. 90kg x12 was too heavy today because arm bend increased and the movement shifted away from clean pec isolation. Do not treat 90kg as the new working load yet.

## Technical theme to carry forward
- Deadlift: wedge harder before initiating. Cue stack: `slack out`, `lats squeezed`, `push floor apart`, then `hips through`.
- Squat: use squat shoes; keep `knees out and slightly forward`; think `shoulders and hips up together` / `chest into the bar` out of the hole.
- Accessories: preserve the movement target. For chest fly, load only counts if the elbow angle stays stable enough to keep it a chest fly, not a bent-arm press.

## Next-time guidance
- Sumo deadlift 6s: 160kg is validated as a strong Week 1 working load. Progress only if warm-ups and set 1 keep the same wedge/lat position.
- Light low-bar after deadlifts: default to squat shoes. 130kg remains fine, but keep it truly light unless position is cleaner than today.
- Larsen 8s: if 100kg is under target again, try 102.5kg before 105kg. Use 105kg only if the goal range is allowed to drift closer to @7.
- Chest fly machine: default 85kg x12 for clean target work. Avoid 90kg until 85kg is clearly below @7 with stable arm angle.
